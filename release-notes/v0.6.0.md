# Gossia 0.6.0: the web version and Gossia pyplot

Gossia 0.6.0 puts Gossia in the browser, on a public site, and adds a
plotting module in the style of matplotlib's `pyplot` for report charts.

## Gossia on the web

Gossia now runs as a web page at **https://wvdveer.github.io/gossia/**. There
is nothing to install, and everything runs in your browser: the site only
serves the files, and nothing of a workbook leaves your machine except the
data source requests you make.

- **Workbooks.** In Chrome and Edge a `.gossia` file is opened, saved and
  saved again in place, without the browser asking for permission each time.
  In Firefox and Safari a workbook is opened by choosing or dropping it and
  saved by downloading it. Up to ten recent workbooks are kept with a copy in
  the browser, so a workbook comes back after the tab is closed, and leaving
  with unsaved changes asks first.
- **Data sources over HTTP** are fetched by the browser, so only sites that
  allow cross-origin requests can be read. A request a site refuses for that
  reason says so, and says that the desktop application and VS Code do not
  have this limit.
- **Secrets** are kept for the session only, unless you tick *Remember on
  this browser* for a data source.
- **Loading.** The page shows what runs where and what the web version
  lacks, in your browser's language, with a progress bar while the
  application downloads.
- **Installable and offline.** The site can be installed as an app, on the
  desktop and on phones and tablets, and opens without a connection (data
  sources over HTTP excepted). A new version downloads in the background and
  is used at the next start; while Gossia is open, a notice offers *Restart
  now*.
- **Phones and tablets.** Touch gives larger targets, and a mouse click
  turns them back. On a narrow window the menus are behind one button, the
  toolbar wraps, the side panels fold away, the formula bar takes two rows,
  and the tree scrolls sideways to its Value and Formula columns. Press and
  hold for what a right click gives. The designers and the code editor are
  not reworked for phones.
- **What the web version lacks** against the desktop is as before: no
  `bidwillii`, no printing, no database or ODBC sources.

## Share files

A workbook can be sent to someone who does not have Gossia as **one `.html`
file**. Opened in a browser, it shows the workbook's name and a button,
**Open in Gossia**, that opens the workbook in the web version. Nothing
passes through a server: the page hands the workbook to the site in the
browser.

- Save one with **File > Save as share file...**, on the desktop, the web
  and in VS Code (*Gossia: Save as Share File...* in the Command Palette), or
  pick *Gossia share file (.html)* in the desktop's *Save As*. It is a copy:
  the workbook keeps its own file.
- From the command line: `bidwillii share <workbook.gossia> --out
  <file.html>`. Nothing in the workbook is run, so it need not be trusted.
- **Gossia reads share files too.** Opening or dropping one, in any version,
  opens the workbook in it as a new workbook named after the original, not
  saved yet and not trusted until you trust it. This is also the way in
  where the button does not work, such as mail programs that show attachments
  without running them.
- Some mail systems refuse `.html` attachments; saving a share file above
  20 MB warns that many will not take it.

## Gossia pyplot

Report charts can be drawn with **`gossia.pyplot`**, available in formulas as
`plt`. Its names and arguments follow matplotlib's `pyplot` where the two
overlap; it is not matplotlib. A chart function starts with `plt.clear()`
and ends with `return plt.svg()`.

- **Figures and axes:** `figure()`, `subplots()` with shared axes, `twinx()`,
  titles, labels, limits, ticks, grids, log and date scales, categories,
  equal aspect and `axis('off')`.
- **Plots:** `plot()` with format strings, `bar`, `barh`, `scatter`, `hist`,
  `pie`, `fill_between`, `errorbar`, `step`, `boxplot`, horizontal and
  vertical lines and spans, `text` and `annotate`, and a legend in
  matplotlib's order with `loc='best'`.
- **Maps:** a world outline (Natural Earth, 1:110m) with a Mercator scale,
  and a built-in **Map** chart.
- `import matplotlib` is refused with a message pointing to `gossia.pyplot`,
  and the code editor (and a quick fix in VS Code) changes the line for you.
  `plt.show()`, `savefig()` and what is not covered are refused by name.
- `plt` and `map_chart` are now reserved names. A tab with such a name in an
  older workbook keeps working in formulas until it is renamed.

## Other changes

- **Hide tabs.** *Hide tab* on a tab's menu (and in the Edit menu) takes it
  off the tab bar; **View > Unhide tab** brings it back by name. One tab
  always stays on the bar. Which tabs are hidden is saved with the workbook,
  as view state, not as an edit.
- **Convert formula to values** is on the tree's row menu as well as the
  cell menu.
- Formulas take JSON's `true`, `false` and `null` as `True`, `False` and
  `None`.
- A chart whose type needs no values now draws without waiting for one.
- The Immediate window keeps the cursor after an expression that takes a
  while.
- The web version starts on phones whose graphics allow textures of only
  4096 pixels.
