Gossia runs entirely in this browser. GitHub only serves its files: your workbooks stay on this computer, and only the requests to the data sources you set up leave it.

The web version cannot print, has no database data sources and no bidwillii command line, and can read a web site only if the site allows it (CORS). The desktop application and the Visual Studio Code extension have none of these limits.
