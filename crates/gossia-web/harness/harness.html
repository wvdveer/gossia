Gossia web test harness

Drives the test build of the application (cargo xtask web --test-control) in other tabs of this browser, through its gossiaControl function: the commands of the desktop's end-to-end tests (DESIGN.md, Web port, 0.3.0, Testing). This page and the application must be served from the same origin, and popups must be allowed for it. Each run clears Gossia's storage for this origin first. Add ?auto to run everything on load, as the Playwright script does.
